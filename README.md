# H2 Produktfinder

Veröffentlichte Fassung des H2 Produktfinders unter **https://finder.h2insektenschutz.de** (GitHub Pages).
Das ist die Hauptadresse des Finders.

Quelle und Pflege: Projektordner `Montage_Page_H2` (nicht öffentlich). Diese Dateien entstehen dort mit
`npm run build` (Ordner `dist/`) und werden unverändert hierher kopiert – hier wird nichts von Hand geändert.

Dieselben Dateien liegen zusätzlich unter https://h2insektenschutz.de/finder/ (Repository `Ionos_H2`).
Beide Adressen müssen denselben Stand zeigen.
